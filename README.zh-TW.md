hatterm 是 [Wave Terminal](https://github.com/wavetermdev/waveterm)（Apache 2.0）的分支，新增了以下功能：

- 擴充的 AI 提供者層 — OpenAI、Anthropic、Gemini、Mistral、xAI、DeepSeek、Cohere、Perplexity、Together AI、Groq、OpenRouter、Ollama、LM Studio、llama.cpp、vLLM、LocalAI
- 終端機工作階段之間的拖放檔案複製（本機及 SSH）
- 內建 AI 使用量計數器（Claude Code、Gemini CLI）

安裝、建置及設定說明請參閱[英文 README](README.md)。
